A small fix for the desktop client of **relay 2.0**.

### Links open in your browser

Clicking a link in chat did nothing in the app — the only way to follow it was
to copy it and paste it into a browser by hand. Links now open in the default
browser of the system, and the app stays where it was.

Attachments behave as before.

Nothing else changes: the app updates itself, and the server needs no update
for this release.
