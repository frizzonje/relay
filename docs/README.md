# Документация relay

| Документ | Для кого | Что внутри |
|---|---|---|
| [architecture.md](architecture.md) | всем, начать отсюда | сервисы, три проверки на входе, контракт и его копии, где живёт состояние, карта репозитория |
| [protocol.md](protocol.md) | тем, кто пишет клиента или трогает гейтвей | REST и все Socket.io-события: пропуска, реестр, чат, ЛС, дозвон, голос, гости, модерация, панель владельца |
| [media.md](media.md) | тем, кто трогает звонки | mesh и perfect negotiation, восстановление связи, протокол медиасервера, simulcast, TURN |
| [backend.md](backend.md) | разработчикам api | старт процесса, устройство гейтвея, сервисы, таблицы, фоновые задачи, настройки, тесты |
| [frontend.md](frontend.md) | разработчикам web | маршруты, как приложение оживает, ключ устройства, сторы, `lib/`, мост к десктопу, языки |
| [self-hosting.md](self-hosting.md) | тем, кто держит сервер | установка, `relay` CLI, обновления, `.env`, firewall, панель владельца, данные, приватность |

Рядом:

- [CONTRIBUTING.md](../CONTRIBUTING.md) — окружение, проверки перед PR, соглашения;
- [CHANGELOG.md](../CHANGELOG.md) — что меняет каждый релиз на вашей машине;
- [clients/](../clients/README.md) — нативные клиенты и их README;
- [plans/](plans/) — проектные заметки по релизам (почему сделано так, а не иначе).
  Это история решений, а не описание текущего кода: если план и код расходятся,
  прав код и документы выше.

Документы ссылаются на код путями и именами символов. `pnpm docs:check`
([`tools/check-docs.mjs`](../tools/check-docs.mjs)) проверяет, что все ссылки
ведут на существующие файлы и что каждое socket-событие описано в
[protocol.md](protocol.md) или [media.md](media.md). Проверка стоит в CI.
