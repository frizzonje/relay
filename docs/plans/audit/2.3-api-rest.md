## Главное

Типовая гонка кодовой базы — «проверка → поход в базу → запись» — нашлась и
здесь, в девяти местах. Лечится одним из трёх способов, по месту:

- **занять до похода** (квоты в памяти): место в квоте, пауза ника, код связки
  ставятся той же синхронной частью, что и проверка, и возвращаются, если дело
  не состоялось;
- **условие в самой записи** (база): `UPDATE … WHERE revoked_at IS NULL`,
  `DELETE … WHERE <условия> RETURNING`, `INSERT … ON CONFLICT … RETURNING`;
- **проверка под замком** (несколько строк): обе личности связки — `FOR UPDATE`
  в одном порядке, проверки внутри транзакции.
