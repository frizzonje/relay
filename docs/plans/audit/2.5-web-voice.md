Голос — это ожидания системы, которые длятся секундами: вопрос «разрешить
микрофон / камеру?», выбор источника экрана, закрытие `AudioContext`, два
запроса подписки к медиасерверу. Все находки партии — про то, что успевает
случиться за это время: второе нажатие, выход из звонка, закрытая дорожка.
